# V3 第一阶段：分块正则化线性比较器
日期：2026-10-29（北京时间）。在已知历史测试分数并完成首轮提交后开展的追加研究。
本阶段只进行训练交叉验证和有限验证，绝不访问测试题、测试标签或测试预测。
已提交 frozen-v1.1、原报告、权重及 GitHub 提交保持不变；本阶段不自动上传或提交结果。

## 研究问题
相同输入、训练题组、标准化及求解条件下：
1. 对 embedding 和人工特征分别设置 L2，是否比单一 L2 更有效？
2. 对所有正确候选均匀分配目标概率的组内 softmax CE，是否优于候选 BCE？
这不是第一轮旧 listwise 的正类总概率目标。

## 固定输入及训练
使用已冻结的 features.py 和 arithmetic_features.py，不修改解析规则。
1024维原始 embedding + 30维原基本/风格/组特征 + 17维原算术特征 = 1071维。
算术17维按既有融合方式在题组内中心化，其余特征不增加相对副本、排名或新交互。
没有旧模型分数作为输入，不复制或加载任何外部模型。
所有4755个训练题参与；uniform题权重，不加入hard-only加权，多个正例全部保留。
每折仅在该折训练候选上拟合列均值和总体标准差；std<1e-8设为1；不裁剪。
BCE=所有候选二元交叉熵平均；CE=每题正确候选均匀分布的softmax交叉熵平均。
两者均加 0.5*(lambda_emb*||w_emb||² + lambda_hand*||w_hand||²)。
BCE截距不罚；CE共同截距不可识别，固定为0。
从零权重出发，NumPy float64确定性L-BFGS，memory=10，gtol=1e-6，最多2000次，
Armijo线搜索最多40次。非收敛不得当作有效候选，记录失败，不追加调参。

## 预先限定的搜索
每种objective各有：
- uniform：lambda_emb=lambda_hand，取0.001、0.01、0.1（3种）。
- block：lambda_emb取0.01、0.1、0.3，lambda_hand取0.001、0.01（6种）。
共18个候选标签、16个不重复配置；完全重合的配置复用同一拟合。
主5折seed=20261022，沿用现有按问题分组、按输入定义disagreement分层的fold算法；
全部4个候选及相同空白规范化问题必须在同折。
每个objective×regularization_family按主OOF disagreement正确数、全体正确数、
较强embedding L2、较强人工L2的顺序确定唯一候选，共最多4个。
该OOF分数用于配置选择，不能宣称是搜索后无偏性能估计。

## 冻结后的有限检查
选定候选先记录配置和哈希，再以第二个5折划分seed=20261029复查，不能据此追加配置。
不随机改变凸优化初值冒充稳定性；两次划分不是独立数据集。
4个候选均在全train重拟合，全部完成后才打开validation。
每个不重复候选只评估一次validation（最多4个），并重新预测已提交冻结模型作配对对照。
使用原版官方预测入口和评分器。记录全体/355个disagreement/其余题的准确率、
修正与损失、描述性配对bootstrap区间、模型大小、完整validation进程耗时。
验证集已被重复使用，不是新盲测。
分块有效性先比较同objective的block与uniform；与旧融合系统的差异包含结构变化，
不能全部归因于分块正则。
进入下一阶段的独立替代候选需：两种训练划分均优于对应uniform，
且validation disagreement比旧融合至少高1个百分点、全体不下降。
不满足替代门槛仍可记录互补性，后续是否融合另行实验，不在本阶段拟合融合。
